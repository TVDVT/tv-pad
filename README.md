# tv-pad
The tv-pad is a 9 key macropad with an OLED display, and uses QMK firmware.
It's main purpose it to help with note taking on 2 in 1 laptops, but can be reprogrammed with any keys.

# Features:
- 9 keys
- 128x32 OLED display

# CAD Model:
Everything fits together using 4 M3 Bolts and heatset inserts. It has 2 separate printed parts: top and bottom. I used Onshape.

# BOM:
- 9x Cherry MX Switches
- 9x DSA keycaps
- 1x 0.91" 128x32 OLED Display
- 4x M3x5mx4mm heatset inserts
- 4x M3x16mm SHCS Bolts
- 6x 1N4148 DO-35 Diodes
- 1x Seeed XIAO RP2040
- 1x Case (2 printed parts)
